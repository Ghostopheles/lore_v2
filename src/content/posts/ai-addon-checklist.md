A brief set of characteristics common to vibecoded WoW addons.

# On the Curseforge Page
- [ ] AI generated icon
- [ ] First project for the author
	- [ ] Bonus point: Insane project scope
- [ ] Emojis everywhere
- [ ] Dramatic name
- [ ] Buzzword soup
	- [ ] “Zero dependencies”
	- [ ] “Lightweight”
	- [ ] “Powerful”
	- [ ] “Everything works”
	- [ ] “Self-contained”
- [ ] “Quickstart” section for no reason
- [ ] Em dashes
- [ ] Bold text proclaiming something insignificant in this context
- [ ] “No X, no Y — just Z.”
- [ ] “No \<thing that barely exists in WoW addons>, ever.”
- [ ] Unnecessary list of features
	- [ ] Bonus point: Each feature has it’s own emoji
- [ ] Egregious UI
	- [ ] Using ancient templates
	- [ ] Looks like it’s from Star Citizen
	- [ ] Abominable UX
	- [ ] Cluttered into oblivion
- [ ] Mentions the file size of the addon
- [ ] Bold tagline “Every tool you can think of. One lightweight addon.”
- [ ] No link to source code

# In the Code
- [ ] Comments everywhere
	- [ ] Bonus point: A comment mentions a “single source of truth”
- [ ] Emojis
- [ ] Code is needlessly defensive
	- [ ] `pcall`’ing everything
	- [ ] Checking if every UI function exists before calling it
- [ ] Everything is an “Engine”
- [ ] Reinventing the wheel
- [ ] Rawdogging addon comms
- [ ] Excessive number of files
- [ ] Filenames have a prefix for no reason
- [ ] `LoadOnDemand: 0` in the `.toc`
- [ ] Non-standard Lua annotations
- [ ] Every file has a giant block of text at the top explaining what it does
- [ ] Inhuman design patterns
- [ ] Links to a private GitHub repo
- [ ] Comments making completely incorrect claims
- [ ] Insane complexity
